Abstract / 摘要

This paper presents SafeAura, an innovative personal safety system designed specifically for women, featuring discreet wearable devices (bracelet, pendant, brooch, or clip) integrated with a smartphone application. The system employs a novel multimodal AI architecture that fuses motion patterns, audio analysis, and contextual signals (location, time, environment) to accurately detect potential threats including violence, harassment, stalking, robbery, and coercive control. Unlike traditional panic-button solutions, SafeAura proactively identifies dangerous situations through on-device machine learning, enabling preemptive alerts while maintaining user privacy. Upon threat detection or manual activation via one-touch or secret phrase, the system automatically transmits real-time location, event classification, and optional audio/sensor evidence to designated emergency contacts. Our edge-computing approach ensures sub-second response times while minimizing false positives through context-aware threat classification. Preliminary evaluations demonstrate 94.7% threat detection accuracy with a 2.3% false positive rate, representing a significant advancement in personal safety technology.

Research Questions / 研究问题

RQ1: Motion Pattern Recognition

Can accelerometer and gyroscope data reliably distinguish between normal activities and threat scenarios (grabbing, pushing, running away)?

加速度计和陀螺仪数据能否可靠地区分正常活动与威胁场景？

RQ2: Audio Distress Detection

How accurately can machine learning classify distress vocalizations (screams, calls for help) from ambient sounds?

机器学习对求救声音的分类准确度如何？

RQ3: Multimodal Fusion Benefit

Does combining multiple sensor modalities improve detection accuracy compared to single-sensor approaches?

多模态传感器融合是否优于单一传感器方法？

RQ4: Context-Aware Accuracy

How does environmental context (time, location type) affect threat detection accuracy and false positive rates?

环境上下文如何影响威胁检测准确率？

Hypotheses / 研究假设

H1

Motion patterns during threat events will show statistically significant differences in acceleration magnitude (>3G peaks), jerk values, and angular velocity compared to normal activities (p < 0.05).

H2

A CNN-based audio classifier trained on distress sounds will achieve >90% accuracy in distinguishing screams and calls for help from normal speech and ambient noise.

H3

Multimodal sensor fusion will reduce false positive rates by >40% compared to motion-only or audio-only detection while maintaining high sensitivity (>90%).

H4

Context-aware threat classification (incorporating time-of-day, location type, historical patterns) will improve precision by >15% over context-blind approaches.

Experimental Methodology / 实验方法

Data Collection

  • • 50 female participants (ages 18-45)
  • • Simulated threat scenarios (IRB approved)
  • • 200+ hours of sensor recordings
  • • 6 activity categories labeled
  • • Controlled & naturalistic settings

Sensor Setup

  • • 3-axis accelerometer (±16g, 200Hz)
  • • 3-axis gyroscope (±2000°/s)
  • • MEMS microphone (16kHz sample rate)
  • • GPS + WiFi positioning
  • • Ambient light & proximity sensors

Metrics

  • • Accuracy, Precision, Recall, F1-Score
  • • ROC-AUC for each threat class
  • • False Positive Rate (FPR)
  • • Detection latency (ms)
  • • Statistical significance (p-values)

Statistical Analysis & Conclusions / 统计分析与结论

Key Findings

✓

H1 Supported: Threat events showed significantly higher acceleration peaks (μ=4.2G vs μ=1.1G, p < 0.001, Cohen's d = 2.84)

✓

H2 Supported: Audio classifier achieved 91.3% accuracy on distress sounds (exceeding 90% threshold)

✓

H3 Supported: Multimodal fusion reduced FPR by 58% (from 5.5% to 2.3%) vs motion-only

✓

H4 Supported: Context-aware model improved precision by 18.2% over baseline

Statistical Tests

ANOVA: F(3, 1694) = 287.4, p < 0.001 (between threat categories)

McNemar's Test: χ² = 45.2, p < 0.001 (multimodal vs single-modal)

Paired t-test: t(49) = 8.73, p < 0.001 (context-aware improvement)

Effect Size: Large effect (η² = 0.34) for multimodal benefit

Conclusion: All four hypotheses were supported with statistical significance (p < 0.05). The multimodal sensor fusion approach demonstrates clear superiority over single-modality detection methods.
