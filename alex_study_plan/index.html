Alex — AI × Biomedical Research Syllabus

Course Content

Phase 01
Vibe Coding — Apps, Websites & Full-Stack
June 4 – 18 · 16 hours
Class Plan
  1. Intro to vibe coding & the AI coding workflow
  2. Claude Code essentials: setup, prompts, iteration
  3. Codex & comparing AI coding tools in practice
  4. Build a static website with AI assistance
  5. Build a mobile-style app prototype (HTML/CSS/JS)
  6. Backend basics: APIs, databases, auth
  7. Full-stack project: connect frontend + backend
  8. Ship, deploy & document on GitHub
Main Deliverables
  • Personal website built with Claude Code
  • Mobile app prototype (1–2 screens)
  • Deployed full-stack mini project
  • GitHub portfolio with README docs
Phase 02
Basic ML & Data Science via Vibe Coding
July 5 – 24 · 16 hours
Class Plan
  1. Data science concepts & the ML mindset
  2. Vibe-code a data cleaning & EDA notebook
  3. Data visualization & pattern discovery
  4. Regression & classification — built with AI
  5. Decision trees & random forests, hands-on
  6. Model evaluation metrics & comparison
  7. Build an interactive ML demo app (Streamlit)
  8. Mini DS/ML project: dataset → model → app
Main Deliverables
  • Cleaned dataset & EDA notebook
  • Trained ML models with evaluation
  • Interactive ML demo app
  • Reusable vibe-coding ML workflow
Phase 03
Biomedical AI Project — Ideate → Present
August 3 – 15 · 16 hours
Class Plan
  1. Ideate — biomedical AI problem brainstorming
  2. Scope — research question & success criteria
  3. Design — dataset selection & system plan
  4. Build I — data prep & baseline model
  5. Build II — model improvement & interpretation
  6. Build III — package into a working prototype
  7. Present — write-up, slides & demo prep
  8. Review — final presentation & next-step plan
Main Deliverables
  • One-page project proposal
  • Working biomedical AI prototype
  • Research summary & slide deck
  • Live final presentation & extension plan
