Data Sources Used for This Analysis (Advanced IMU Feature)

Primary Data Channels:

  • Lateral Acceleration - Y-axis G-force (100Hz IMU)
  • Longitudinal Acceleration - X-axis G-force (100Hz IMU)
  • GPS Position - For track position correlation
  • Gyroscope - Yaw rate for slip detection (optional)

How Data Contributes:

  • • Longitudinal G measures braking/acceleration intensity
  • • Lateral G measures cornering forces
  • • G-G diagram plots combined grip utilization
  • • Rate-of-change of G-forces indicates input smoothness
  • • Slip events detected from sudden lateral G spikes

Device Requirement: This analysis requires an IMU (Inertial Measurement Unit) equipped data logger. Not all devices include IMU sensors.
