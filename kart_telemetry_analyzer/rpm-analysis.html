Data Sources Used for This Analysis

Primary Data Channels:

  • RPM - Engine speed from inductive pickup (50-100Hz)
  • GPS Position - For track position correlation
  • GPS Speed - For gear ratio inference

How Data Contributes:

  • • RPM channel directly measures engine revolutions
  • • Power band range (user-configurable or engine spec)
  • • Rev limiter detection via sustained peak RPM
  • • Gear ratio suggestions calculated from RPM/Speed ratio

Setup Required: RPM sensor wire must be connected to spark plug lead or ECU signal. Power band limits should be configured in settings based on your engine specification.
