Data Sources Used for This Analysis

Primary Data Channels:

  • GPS Speed - Velocity from GPS module (km/h, 25Hz)
  • GPS Position - For track position mapping
  • Timestamp - Time synchronization for lap alignment

How Data Contributes:

  • • GPS speed channel provides instant velocity readings
  • • Speed trace plotted against distance/track position
  • • Min/max speed detection for corner apex & exit analysis
  • • Speed differential calculated between comparison laps

Accuracy Note: GPS-derived speed is typically accurate to ±0.5 km/h. For higher precision, wheel speed sensors can supplement GPS data (optional channel).
