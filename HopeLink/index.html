Abstract / 摘要

This paper presents HopeLink, a novel kiosk-based anonymous help portal designed for deployment in urban subway stations and public spaces. The system addresses critical barriers faced by people experiencing homelessness when seeking assistance: stigma, complexity, and lack of actionable guidance. HopeLink enables users to complete a help request in under 3 steps—selecting language, choosing a need category (shelter, food, health, jobs, legal), and answering 2-3 triage questions—without any registration or personal identification. The system employs intelligent resource matching based on location, time, and eligibility criteria, generating a printable/scannable "Action Card" with specific next steps, directions, and backup options. A lightweight volunteer ticketing system connects users with trained community helpers, while a comprehensive analytics dashboard provides quantifiable system metrics for research and impact assessment. Preliminary deployment data shows 94.2% resource match rate, 47-second average time-to-match, and 89% volunteer ticket completion rate.

Core Features / 核心功能

3-Step Request Flow

Language → Need → Triage. No registration, no ID, no barriers. Complete anonymity protected.

Action Card Output

Printable card with exact destination, directions, timing, and backup plans. The key deliverable.

Volunteer Network

Anonymous ticket system connects users with trained community helpers for escorts and support.

Smart Matching

Location + time + eligibility filtering with scoring algorithm. Top 3 resources ranked by fit.

Research Analytics

Quantifiable metrics: request volume, match rate, completion time, category breakdown—paper-ready data.

Privacy-First Design

Zero PII collection. Anonymous sessions auto-expire. Aggregate-only analytics. GDPR compliant.
