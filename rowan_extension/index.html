Rowan
Chrome extension · family safety

A filter that explains itself, to the parent and to the child.

Rowan filters three things on the family computer: web content, music lyrics, and what children do with generative AI. Every block carries a reason. The child can see the same rules the parent set, and can argue with them.

Fifteen web categories, per child
Block, warn, or allow. Warn loads behind a notice.
Lyrics checked on five web players
Mutes one line rather than killing the song.
AI use sorted into five kinds, no transcripts
The parent sees categories and time. Never the words.

Prototype. Eight screens at 1440 by 900, plus the extension popup at 380 wide. Household data is invented for the demo, and the charts are labelled illustrative. Track and artist names are fictional so that no real release is shown as flagged.
