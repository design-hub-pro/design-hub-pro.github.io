Section I

Abstract

Neural network training via gradient descent is typically understood as an iterative optimization procedure. However, a deeper mathematical perspective reveals that gradient descent can be modeled as a continuous-time dynamical system governed by ordinary differential equations (ODEs). This research investigates this ODE viewpoint to analyze the training dynamics of a single-layer linear neural network.

By computing the Hessian matrix H = 2XTX of the squared-error loss and analyzing its eigenvalue spectrum, we derive a precise stability criterion for the learning rate: convergence is guaranteed when 0 < η < 2/λmax(H). We validate this theoretical bound through controlled experiments comparing discrete gradient descent with continuous ODE simulation (Euler method), demonstrating three regimes — stable convergence, critical oscillation, and divergence.

This work bridges differential equations, linear algebra, and machine learning optimization, providing a mathematically rigorous and experimentally verifiable framework for understanding how learning rate and curvature interact to determine training success or failure.

Section II

Research Questions

Three questions guide this investigation, connecting classical mathematics to modern AI training dynamics.

RQ1
ODE Approximation Fidelity
How accurately does the continuous ODE model dw/dt = -∇L(w) approximate the discrete gradient descent trajectory wk+1 = wk - η∇L(wk), and under what conditions (learning rate, step size) does the approximation break down?
RQ2
Eigenvalue-Based Stability Prediction
Can the eigenvalue spectrum of the Hessian matrix H = 2XTX accurately predict the critical learning rate threshold that separates stable convergence from oscillation and divergence in gradient descent?
RQ3
Convergence Rate Characterization
How do the eigenvalue distribution (condition number, spectral gap) and learning rate jointly determine the convergence rate, and what is the optimal learning rate that maximizes convergence speed without inducing instability?

Section III

Mathematical Framework

Four pillars of mathematics underpin the analysis — each connecting classical theory to neural network training behavior.

∂

Ordinary Differential Equations

dw/dt = -∇L(w) = -2XT(Xw - y)

Gradient descent is reinterpreted as a first-order autonomous ODE. The weight vector w(t) evolves continuously toward the loss minimum, with the gradient field defining the flow. Numerical integration (Euler method) bridges the continuous model to computable trajectories.

λ

Eigenvalue Analysis

H = 2XTX,  eigenvalues λ₁ ≤ λ₂ ≤ ... ≤ λd

The Hessian's eigenvalues encode the curvature of the loss landscape along each principal direction. The largest eigenvalue λmax determines the steepest direction and sets the upper bound for stable learning rates. The condition number κ = λmax/λmin characterizes problem difficulty.

∇

Optimization Theory

wk+1 = wk - η · 2XT(Xwk - y)

Gradient descent iteratively updates weights in the direction of steepest loss decrease. The learning rate η controls step size — too small yields slow convergence, too large causes oscillation or divergence. The quadratic loss guarantees a unique global minimum for the linear model.

⟨⟩

Linear Algebra Foundation

L(w) = ‖Xw - y‖² = (Xw-y)T(Xw-y)

The linear model ŷ = Xw operates in a well-understood algebraic framework. XTX is symmetric positive semi-definite, ensuring real non-negative eigenvalues. The normal equation XTXw = XTy gives the closed-form optimum, serving as ground truth for comparing iterative methods.

Section IV

Methodology

A five-stage pipeline from data synthesis through eigenvalue analysis to experimental validation.

01 Synthetic Data Generation

Construct a controlled dataset: X ∈ ℝn×d (n=300 samples, d=6 features) drawn from N(0,1), with true weights wtrue = [2.0, -1.0, 0.5, 0.0, 1.5, -0.7] and Gaussian noise σ=0.2. This gives a known ground truth for validating convergence accuracy.

02 Hessian & Eigenvalue Computation

Compute the Hessian H = 2XTX and its eigenvalue spectrum using numpy.linalg.eigvalsh. Extract λmax, λmin, condition number κ, and the theoretical stability bound ηcrit = 2/λmax. These quantities fully characterize the loss landscape's curvature.

03 Discrete Gradient Descent Simulation

Implement standard GD: wk+1 = wk - η∇L(wk). Run with three learning rates — stable (0.8 · ηcrit), critical (~ηcrit), and unstable (1.2 · ηcrit) — for 250 iterations. Record loss L(wk) and weight distance ‖wk - wtrue‖ at each step.

04 Continuous ODE Simulation

Solve dw/dt = -∇L(w) numerically using Euler integration with small time step Δt. Compare the ODE trajectory to discrete GD to validate the continuous approximation. Optionally use scipy.integrate.solve_ivp (RK45) as a high-accuracy reference.

05 Comparative Analysis & Visualization

Generate loss curves (log scale), weight convergence plots, phase portraits (w₁ vs w₂), and eigenvalue spectrum diagrams. Quantify GD-ODE trajectory divergence as a function of η. Validate theoretical stability bound against empirical critical threshold.

import numpy as np # Synthetic data np.random.seed(0) n, d = 300, 6 X = np.random.randn(n, d) w_true = np.array([2.0, -1.0, 0.5, 0.0, 1.5, -0.7]) y = X @ w_true + 0.2 * np.random.randn(n) # Hessian eigenvalues → stability bound H = 2 * (X.T @ X) lam_max = np.linalg.eigvalsh(H).max() eta_crit = 2 / lam_max # theoretical stability bound # Three regimes eta_stable = 0.8 * eta_crit # converges eta_critical = 1.0 * eta_crit # oscillates eta_unstable = 1.2 * eta_crit # diverges

Section V

Experimental Design

Three learning rate regimes, predicted by eigenvalue analysis, produce fundamentally different training behaviors.

✓

Stable Convergence

η = 0.8 · (2/λmax)

Loss decreases monotonically. Weights converge smoothly to wtrue. ODE and GD trajectories closely match. System is well within the stability region.

~

Critical Oscillation

η ≈ 2/λmax

Loss oscillates around the minimum without converging cleanly. Weights exhibit damped or sustained oscillation. System sits at the stability boundary — sensitive to perturbation.

✕

Divergence

η = 1.2 · (2/λmax)

Loss increases exponentially. Weights diverge from optimum. Spectral radius of update matrix exceeds 1 — confirming the eigenvalue prediction of instability.

Expected Results

Five key findings that connect mathematical theory to observable training phenomena.

Eigenvalue Spectrum Report

Compute and visualize all d eigenvalues of H = 2XTX. Report λmax, λmin, condition number κ, and the resulting stability bound. Expect κ ≈ 3–8 for random Gaussian data, yielding a well-conditioned but non-trivial optimization landscape.

Stability Bound Validation

Demonstrate that GD converges for η < 2/λmax and diverges above. Plot empirical critical η vs. theoretical prediction. Expect <5% discrepancy, confirming the eigenvalue criterion as a precise stability predictor.

GD vs. ODE Trajectory Comparison

Show loss curves and weight trajectories for discrete GD and continuous ODE side-by-side. At small η, curves nearly overlap; as η → ηcrit, discretization effects create visible trajectory splitting.

Phase Portrait Analysis

2D projections (w₁ vs w₂) show spiral convergence in the stable regime, limit-cycle oscillation at criticality, and outward spiraling divergence above threshold — visually confirming dynamical systems behavior.

Section VIII

Significance & Contributions

This research bridges classical mathematics and modern AI, with both theoretical and practical implications.

01

Mathematical understanding of AI training — Demonstrates that neural network training is not a black box, but a dynamical system whose behavior is predictable from the eigenvalue spectrum of the loss landscape's Hessian matrix.

02

Principled learning rate selection — Provides a computable, theory-grounded criterion (η < 2/λmax) for choosing safe learning rates, replacing trial-and-error hyperparameter tuning with mathematical prediction.

03

ODE-GD equivalence validation — Empirically quantifies when the continuous ODE model faithfully approximates discrete gradient descent, establishing the validity conditions for gradient flow analysis in optimization research.

04

Interdisciplinary bridge — Connects differential equations (dynamical systems theory), linear algebra (eigenvalue analysis), and optimization (gradient descent) into a unified framework accessible to students from any of these backgrounds.

05

Foundation for deeper analysis — Establishes a methodology that can be extended to non-linear networks, stochastic gradient descent (SGD), adaptive optimizers (Adam), and deep network loss landscape analysis.
