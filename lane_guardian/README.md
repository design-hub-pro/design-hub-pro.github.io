## Abstract / 摘要

### English

This paper presents LaneGuard, an innovative smart device system designed for in-vehicle lane detection and real-time driving feedback. The system integrates advanced computer vision algorithms with edge computing capabilities to provide continuous lane monitoring and instant driver alerts. LaneGuard employs a multi-sensor fusion approach, combining high-resolution camera modules with infrared sensors for all-weather operation, processed through a dedicated neural processing unit (NPU) for low-latency inference. The core innovation lies in our proprietary lane departure prediction algorithm, which anticipates potential deviations 2-3 seconds before occurrence, enabling proactive safety interventions. The companion mobile application provides comprehensive driving analytics, historical trip data, and personalized safety recommendations. Field testing across diverse road conditions demonstrates a 94.7% accuracy rate in lane detection and a 40% reduction in lane departure incidents among users. LaneGuard represents a significant advancement in accessible driver assistance technology, offering premium safety features at consumer-friendly pricing.

### 中文

本文介绍了LaneGuard——一种创新的智能车载车道检测与实时驾驶反馈系统。该系统将先进的计算机视觉算法与边缘计算能力相结合，提供持续的车道监控和即时驾驶员预警。LaneGuard采用多传感器融合方案，将高分辨率摄像头模块与红外传感器相结合，实现全天候运行，并通过专用神经网络处理单元（NPU）进行低延迟推理。核心创新在于我们专有的车道偏离预测算法，能够在偏离发生前2-3秒预测潜在风险，实现主动安全干预。配套的移动应用程序提供全面的驾驶分析、历史行程数据和个性化安全建议。在各种路况下的实地测试表明，车道检测准确率达94.7%，用户车道偏离事件减少40%。LaneGuard代表了可及性驾驶辅助技术的重大进步，以消费者友好的价格提供高端安全功能。

## Features / 功能特点

### Core Features / 核心功能
1. **Real-time Lane Detection** / 实时车道检测
2. **Lane Departure Warning** / 车道偏离预警
3. **Drowsiness Detection** / 疲劳驾驶检测
4. **Speed Monitoring** / 速度监控
5. **Trip Recording & Analytics** / 行程记录与分析
6. **Emergency Alert System** / 紧急警报系统

### Technical Specifications / 技术规格
- Processing Unit: ARM Cortex-A78 + NPU
- Camera: 4K HDR with 120° FOV
- Connectivity: Bluetooth 5.2, Wi-Fi 6, 4G LTE
- Storage: 32GB eMMC + Cloud Sync
- Power: 12V vehicle power with battery backup
