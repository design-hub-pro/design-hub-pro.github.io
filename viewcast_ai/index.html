BUILT ON 5 FREE PUBLIC APIs

All data is collectible today — no scraping required.

Everything ViewCast learns from comes from official, free, rate-limited APIs. We documented the exact endpoint each signal pulls from so the prototype is reproducible in a single weekend.

YouTube Data API v3
Category id=20 (Gaming). Pulls video metadata, title, tags, thumbnail URL, view/like/comment counts, upload time. 10K units/day free.
videos.list · search.list
Twitch Helix API
Real-time concurrent viewers per game — the cleanest "is this game hot right now" signal. Free with client credentials.
/helix/games/top · /streams
Steam Web API
Concurrent players per appid, release dates, top sellers. No auth needed for the public endpoints we use.
GetNumberOfCurrentPlayers · GetAppList
IGDB API
Game canonical IDs, genres, platforms, release dates, franchises. Twitch-owned, free 4 req/sec.
/games · /release_dates
Reddit API
Per-game subreddit post velocity & upvote rate — early signal that beats Twitch by ~24h for indie hits.
/r/{game}/new.json
Step 1 · Collect
~80K labeled gaming videos in 7 days
Cron pulls YouTube Gaming-category trending + search across the top 200 IGDB titles, joined with Twitch CCU and Steam players at each upload's timestamp. Fits comfortably in a single 10K/day quota.
Step 2 · Featurize
28 signals per video
Game ID match · video-format classifier (Highlights / Guide / Tier List / Patch / Lore) · thumbnail CV (face, kill-count, rank badge, contrast) · title NLP · days-from-patch · Twitch heat at upload · channel's per-game baseline.
Step 3 · Predict
Gradient-boosted regressor → 30-day views
XGBoost on log-views, channel-fixed-effects baseline, with conformal prediction for a calibrated confidence band. ~2 hours to train on a laptop. Re-trains weekly.
