Basic Background

A trial-and-error path to a stable landing policy

Rocket landing is a challenging control problem. A rocket must land safely while managing fuel, speed, position, angle, and engine thrust. The system is difficult because the rocket is unstable, nonlinear, and affected by gravity and motion constraints.

Traditional control methods use physics-based models and mathematical controllers. Reinforcement learning provides another approach: an agent learns how to control the rocket by repeatedly trying to land in a simulated environment. The agent observes the rocket's state, chooses an action, receives a reward or penalty, and gradually learns a better landing policy.

This topic is more AI-related than the first two, but it is still strongly connected to algorithms, control theory, simulation, optimization, and sequential decision-making.

Brief Research Plan

Five-step training & evaluation pipeline

Simulator → reward design → RL training → baseline comparison → evaluation under multiple conditions.

1
Create or use a rocket landing simulator
  • Start with a 2D simulation.
  • State variables may include position, velocity, angle, angular velocity, and fuel.
  • Actions may include main engine thrust and side thrusters.
2
Define the reward function
  • Positive reward for safe landing.
  • Penalty for crashing.
  • Penalty for high landing speed.
  • Penalty for using too much fuel.
  • Penalty for large tilt angle near landing.
3
Train reinforcement learning models
  • Start with a standard RL algorithm such as Q-learning for simple discrete control or PPO/DQN for more advanced simulation.
  • Train over many simulated landing attempts.
4
Compare with baseline controllers
  • Random controller.
  • Rule-based controller.
  • Proportional control or simple physics-based controller.
5
Evaluate performance
  • Landing success rate.
  • Average fuel consumption.
  • Final landing speed.
  • Final landing distance from target.
  • Robustness under different initial conditions.
