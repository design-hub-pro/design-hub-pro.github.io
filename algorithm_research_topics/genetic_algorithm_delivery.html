Basic Background

From shortest path to the best visiting order

Multi-stop delivery routing is a classic optimization problem. A driver or delivery vehicle must visit many locations while minimizing total travel distance, travel time, fuel cost, or late deliveries. This problem is closely related to the Traveling Salesman Problem (TSP) and the Vehicle Routing Problem (VRP).

A simple shortest-path algorithm such as Dijkstra can find the shortest path between two locations, but it does not directly solve the harder question: what is the best order to visit many delivery stops? As the number of stops increases, the number of possible routes grows extremely quickly. For example, 10 stops already create millions of possible orderings.

A genetic algorithm is useful because it does not need to check every possible route. Instead, it starts with many possible routes, evaluates them using a fitness function, keeps better routes, combines parts of good routes, adds small mutations, and gradually improves the solution.

Core Research Question
Can a genetic algorithm efficiently find near-optimal multi-stop delivery routes under real-world constraints such as distance, delivery deadlines, and vehicle capacity?

Brief Research Plan

Five-step methodology

From data collection through evaluation, with a hybrid Dijkstra + GA option.

1
Create or collect delivery-location data
  • Use a small city map, school campus map, or simulated delivery points.
  • Each location has coordinates, demand size, and optional delivery deadline.
2
Build baseline algorithms
  • Nearest-neighbor greedy algorithm.
  • Random route generation.
  • Optional: exact brute-force search for very small cases.
3
Implement the genetic algorithm
  • Each chromosome represents one possible delivery order.
  • Fitness function measures total distance, lateness penalty, and capacity penalty.
  • Use selection, crossover, and mutation to evolve routes.
4
Optional hybrid design
  • Use Dijkstra to compute shortest-path distances between all pairs of delivery locations.
  • Use genetic algorithm to optimize the visiting order.
5
Evaluate performance
  • Compare route distance, runtime, number of late deliveries, and scalability.
  • Test with 10, 20, 50, and 100 stops.
