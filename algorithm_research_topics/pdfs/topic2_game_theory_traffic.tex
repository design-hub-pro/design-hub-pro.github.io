\section{Basic Background}

Traffic congestion is not only a shortest-path problem. It is also a \textbf{multi-agent decision-making problem}. Every driver wants to choose the fastest route for themselves. However, if too many drivers choose the same ``best'' route, that route becomes crowded and may become slower for everyone.

This creates a classic game-theory situation called \textbf{selfish routing}. Each driver acts rationally from their own perspective, but the overall system may become inefficient. In traffic theory, this is often studied using \textbf{Wardrop equilibrium}, where no driver can improve their travel time by switching routes alone. However, this equilibrium may not be socially optimal.

The gap between selfish behavior and system-wide optimal routing is often measured by the \textbf{Price of Anarchy}. It asks: how much worse can the total traffic outcome become when every driver optimizes only for themselves?

\section{Research Question}

\noindent\textit{\textbf{Can a game-theoretic traffic-routing algorithm reduce overall congestion compared with selfish shortest-path routing?}}

\subsection*{Possible sub-questions}
\begin{enumerate}
    \item How much worse is selfish routing compared with system-optimal routing?
    \item Can incentive-based routing improve total traffic flow?
    \item What happens when only some drivers follow the recommended route?
    \item How does traffic demand affect congestion and equilibrium behavior?
\end{enumerate}

\section{Brief Research Plan}

\begin{enumerate}
    \item \textbf{Build a traffic network simulation}
    \begin{itemize}
        \item Model roads as a graph.
        \item Nodes represent intersections.
        \item Edges represent roads with travel-time functions.
        \item Travel time increases as more cars use the same road.
    \end{itemize}

    \item \textbf{Implement baseline routing}
    \begin{itemize}
        \item Selfish shortest-path routing: every driver chooses the fastest route for themselves.
        \item System-optimal routing: assign drivers to minimize total travel time.
    \end{itemize}

    \item \textbf{Implement game-theoretic routing}
    \begin{itemize}
        \item Simulate drivers repeatedly choosing routes.
        \item Allow route choices to converge toward equilibrium.
        \item Add optional incentives, such as rewards for choosing less congested roads.
    \end{itemize}

    \item \textbf{Compare routing strategies}
    \begin{itemize}
        \item Average travel time.
        \item Total system travel time.
        \item Congestion on each road.
        \item Fairness among drivers.
        \item Stability of route choices.
    \end{itemize}

    \item \textbf{Extend the study}
    \begin{itemize}
        \item Test simple networks first, such as two parallel roads.
        \item Then test a larger city-style network.
        \item Study how results change as the number of drivers increases.
    \end{itemize}
\end{enumerate}

\section{Expected Outcome}

The project should demonstrate that individual shortest-path routing can lead to inefficient traffic patterns, while game-theoretic or incentive-aware routing can improve system-wide performance. This topic is strong because it combines graph algorithms, game theory, simulation, and real-world transportation problems.
