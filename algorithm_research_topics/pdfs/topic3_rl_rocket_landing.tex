\begin{abstract}
\noindent
Rocket landing is a challenging control problem in which a rocket must land safely while managing fuel, speed, position, angle, and engine thrust. The system is unstable, nonlinear, and affected by gravity and motion constraints. Traditional control uses physics-based models and mathematical controllers; reinforcement learning offers an alternative in which an agent learns a landing policy through repeated trials in a simulated environment. This document proposes a practical research project that investigates whether a reinforcement learning agent can learn a stable and fuel-efficient rocket landing policy in a simulated environment, and outlines the background, the core research question and sub-questions, a five-step research plan, the expected outcome, and source references.

\section{Basic Background}

Rocket landing is a challenging control problem. A rocket must land safely while managing fuel, speed, position, angle, and engine thrust. The system is difficult because the rocket is unstable, nonlinear, and affected by gravity and motion constraints.

Traditional control methods use physics-based models and mathematical controllers. Reinforcement learning provides another approach: an agent learns how to control the rocket by repeatedly trying to land in a simulated environment. The agent observes the rocket's state, chooses an action, receives a reward or penalty, and gradually learns a better landing policy.

This topic is more AI-related than the first two, but it is still strongly connected to algorithms, control theory, simulation, optimization, and sequential decision-making.

\section{Research Question}

\noindent\textit{\textbf{Can a reinforcement learning agent learn a stable and fuel-efficient rocket landing policy in a simulated environment?}}

\subsection*{Possible sub-questions}
\begin{enumerate}
    \item Which reward design leads to better landing performance?
    \item Can the agent balance landing accuracy and fuel efficiency?
    \item How robust is the learned policy under wind, sensor noise, or different starting positions?
    \item How does reinforcement learning compare with a simple rule-based controller?
\end{enumerate}

\section{Brief Research Plan}

\begin{enumerate}
    \item \textbf{Create or use a rocket landing simulator}
    \begin{itemize}
        \item Start with a 2D simulation.
        \item State variables may include position, velocity, angle, angular velocity, and fuel.
        \item Actions may include main engine thrust and side thrusters.
    \end{itemize}

    \item \textbf{Define the reward function}
    \begin{itemize}
        \item Positive reward for safe landing.
        \item Penalty for crashing.
        \item Penalty for high landing speed.
        \item Penalty for using too much fuel.
        \item Penalty for large tilt angle near landing.
    \end{itemize}

    \item \textbf{Train reinforcement learning models}
    \begin{itemize}
        \item Start with a standard RL algorithm such as Q-learning for simple discrete control or PPO/DQN for more advanced simulation.
        \item Train over many simulated landing attempts.
    \end{itemize}

    \item \textbf{Compare with baseline controllers}
    \begin{itemize}
        \item Random controller.
        \item Rule-based controller.
        \item Proportional control or simple physics-based controller.
    \end{itemize}

    \item \textbf{Evaluate performance}
    \begin{itemize}
        \item Landing success rate.
        \item Average fuel consumption.
        \item Final landing speed.
        \item Final landing distance from target.
        \item Robustness under different initial conditions.
    \end{itemize}
\end{enumerate}

\section{Expected Outcome}

The project should show how reinforcement learning can learn a control strategy through trial and error. A strong version of the project would compare different reward functions and show how reward design affects safety, fuel efficiency, and stability.
