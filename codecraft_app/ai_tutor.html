Can you explain how binary search works and show me an implementation?
Binary search works by repeatedly dividing the search space in half. It requires a sorted array and runs in O(log n) time.

Here's how it works:
1. Compare target with middle element
2. If equal, we found it
3. If target is smaller, search left half
4. If target is larger, search right half
def binary_search(arr, target):
  left, right = 0, len(arr) - 1
  while left <= right:
    mid = (left + right) // 2
    if arr[mid] == target:
      return mid
    elif arr[mid] < target:
      left = mid + 1
    else:
      right = mid - 1
  return -1
What happens if the array isn't sorted?
Great question! If the array isn't sorted, binary search will give incorrect results because the assumption that elements are ordered breaks down.

You'd need to either:
• Sort first: O(n log n) + O(log n)
• Use linear search: O(n)
