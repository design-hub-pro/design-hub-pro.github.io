App Structure & User Flow

Map every screen and every tap. From "open the app" to "share an order with friends" — design the path so it feels obvious. This is the milestone where your app starts to feel real.

⏱ ~60 min
+200 XP
Real-life context Every product designer starts a flow on paper. Frames + arrows + a pen.
🗺️ M4 · Architecture

📌 What you'll do

Turn your features into screens, and screens into a tappable path.

1List 5–7 main app pages.
2Sketch the user flow from open → action.
3Write 1 example user journey end-to-end.

💡 AI prompt to start with

User flow
"For a teen milk tea app called Boba.Lab with these 3 core features [paste yours], list the 6 main app screens needed and write the step-by-step user flow for a first-time user, from opening the app to placing their first squad order. Highlight any friction points."
Tip — If your flow has more than 4 taps to do anything important, cut. Teens close apps in 8 seconds.
