METHODOLOGY OVERVIEW

From a raw satellite tile to a 5-class environmental footprint, in 6 stages.

We pair high-resolution NAIP imagery with medium-resolution Sentinel-2 time series. A DeepLabV3+ semantic segmentation model labels every pixel into one of five classes; a CRF post-pass smooths boundaries. Outputs are written as GeoTIFFs with class probabilities and converted to per-course aggregates.

End-to-end pipeline
Each stage is independently testable; outputs are cached.
1
Ingest
Pull NAIP/Sentinel-2 tiles for the course bounding box from Earth Engine.
2
Preprocess
Cloud mask, atmospheric correction, resample to 1 m, clip to course polygon.
3
Index pre-pass
Compute NDVI, NDWI, BSI; attach as extra input channels.
4
Segment
DeepLabV3+ (ResNet101) inference at 512×512 sliding windows.
5
Refine
Dense CRF post-processing smooths boundaries and recovers thin features.
6
Aggregate
Per-class area, NDVI cycles, ecology score, write GeoTIFF + JSON.

Model architecture
DeepLabV3+ with ResNet-101 backbone, 5-class head, ASPP rates {6,12,18}
Input · (B, 7, 512, 512) RGB + NIR + NDVI + NDWI + BSI
↓ Backbone · ResNet-101 (pretrained ImageNet)
↓ ASPP · dilation rates 6 / 12 / 18 + global avg pool
↓ Decoder · skip from layer-1 (256→48) ∥ ASPP (256)
↓ 3×3 conv ×2 → 1×1 conv → 5-class logits
↓ Upsample ×4 → softmax
↓ Dense CRF (10 iters, bilateral + Gaussian)
Output · (B, 5, 512, 512) probabilities

Limitations and bias
Geographic skew
Training set is 62% US-based; we report per-region metrics to surface drift.
Seasonal sensitivity
NDVI-based confusion in mid-summer between cool-season turf and rough.
Irrigation model
Water-use estimates are modeled, not metered; ±25% expected error.
