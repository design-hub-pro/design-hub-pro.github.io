Attune

A cognitive operating system for students. It measures how long attention holds in four modes, reads the situations you misread, and rehearses the conversations you dread.
Attention TrainingAI SimulationCognitive ReframingAdaptive Learning
The metric that matters is on screen 12. Requests for help go down, not up. An app that trains judgement should make itself less necessary, and the product has to be able to show that.
