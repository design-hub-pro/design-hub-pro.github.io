Curriculum

Detailed Lesson Plan

Each lesson includes specific learning content and hands-on deliverables

🔧
Phase I
Build Your AI Super Brain (Hardware Assembly)
Lessons 1–4
LESSON 01
Meet the "Heart" & "Brain" of a Computer
Understand how CPU and GPU divide work differently for gaming vs. AI training
🎯 Deliverable: Design your own AI training PC build spec sheet
LESSON 02
Hands-On: Motherboard & Core Assembly
Physically install CPU, RAM modules, and SSD
🎯 Deliverable: Complete the physical assembly of core PC components
LESSON 03
Install the Power Engine: GPU Setup
Learn GPU installation and power supply wiring
🎯 Deliverable: Successfully install GPU and understand why AI training depends on it
LESSON 04 Milestone
First Boot: System & Environment Setup
Install Windows OS and GPU drivers
🎯 Deliverable: Successfully boot up, ready for coding and AI training
🎮
Phase II
Build Your Cartoon Arena (Game Development)
Lessons 5–10
LESSON 05
First Steps: Enter the World of Unity
Get familiar with Unity's interface, import cartoon-style assets
🎯 Deliverable: Build a colorful cartoon sports arena
LESSON 06
Scene Design & Spatial Layout
Place obstacles, target points, and arena boundaries
🎯 Deliverable: Create a complete virtual sandbox ready for game battles
LESSON 07
Bring Characters to Life
Learn basic C# programming syntax
🎯 Deliverable: Write code to make cartoon characters move with keyboard controls
LESSON 08
Set the Rules of the Game World
Learn about Colliders and trigger mechanisms
🎯 Deliverable: Implement "collect coins for points" and "hit obstacles to fail" logic
LESSON 09
Design a "Traditional" Computer Opponent
Write simple conditional logic (If-Else)
🎯 Deliverable: Create a non-intelligent NPC that clumsily patrols a fixed route
LESSON 10 Milestone
Phase Review: Run the Base Game
Fix code bugs and optimize game feel
🎯 Deliverable: Complete a playable cartoon arena mini-game
🧠
Phase III
Awaken the AI Player (Reinforcement Learning)
Lessons 11–18
LESSON 11
How Does AI Get Smart?
Understand states, actions, and rewards in reinforcement learning
🎯 Deliverable: Build the mental model of AI learning through trial-and-error
LESSON 12
Build AI's Training Gym
Configure ML-Agents training environment in Unity
🎯 Deliverable: Connect C# and Python environments, ready to start training
LESSON 13
Write AI's "Coaching Rules"
Define AI reward and penalty conditions in code
🎯 Deliverable: Establish clear goal guidance — teach AI what a "good move" is
LESSON 14
First Training: Witness the Magic
Run training commands in the terminal, leveraging GPU compute
🎯 Deliverable: Watch AI evolve from random bumbling to navigating toward goals
LESSON 15
Increase Difficulty: Dynamic Obstacles
Introduce moving distractors and adjust training parameters
🎯 Deliverable: Train AI to adapt flexibly in complex environments
LESSON 16
Prevent AI's "Shortcuts"
Fix reward loopholes and prevent Reward Hacking
🎯 Deliverable: Guide AI to adopt the most efficient, rule-abiding strategies
LESSON 17
Give AI Perception: Ray Sensors
Learn to use Raycast Sensors
🎯 Deliverable: Give AI "vision" to detect walls and enemies ahead
LESSON 18 Milestone
Phase Review: AI Challenge Test
Independently export and deploy models in a new environment
🎯 Deliverable: Trained AI autonomously and flawlessly clears the entire arena
⚔️
Phase IV
Advanced Challenge (Adversarial & Imitation)
Lessons 19–24
LESSON 19
Introduce Competition: AI vs AI
Duplicate agents and configure multi-agent training environments
🎯 Deliverable: Set up two AIs ready to compete in the same arena
LESSON 20
Peak Evolution: Adversarial Training
Set up chase-and-escape game theory rules
🎯 Deliverable: Observe two AIs continuously improving through mutual competition
LESSON 21
New Concept: What is Imitation Learning?
Understand how AI learns by observing humans (Imitation Learning)
🎯 Deliverable: Master a training method that skips complex rewards — AI "copies the homework"
LESSON 22
Data Collection: Record Pro-Level Play
William plays through perfectly, recording action data
🎯 Deliverable: Generate a high-quality player demonstration dataset for AI training
LESSON 23
AI Learns from the Master
Feed recorded data into a neural network for training
🎯 Deliverable: Train a personalized AI that inherits William's gameplay style
LESSON 24 Milestone
Phase Review: Tactical Debrief
Compare the real-world results of adversarial vs. imitation training
🎯 Deliverable: Analyze which training approach suits the cartoon arena game best
🕹️
Phase V
Build the Console & Motion-Control Showdown (Interactive Experience)
Lessons 25–30
LESSON 25
Design the Game Console Interface
Learn to build UI frameworks with Unity Canvas
🎯 Deliverable: Design your own custom game control panel layout
LESSON 26
Develop Dynamic UI Widgets
Write code to control interactive UI changes
🎯 Deliverable: Create sleek real-time dashboards, buttons, and parameter sliders
LESSON 27
Data Binding: Bring the Panel to Life
Bind AI's backend data to frontend UI Widgets
🎯 Deliverable: View AI win-rate predictions and runtime status live in the game UI
LESSON 28
Introduce Black Tech: Markerless Pose Estimation
Configure computer vision libraries to capture real human motion
🎯 Deliverable: Achieve camera-based motion control with zero wearable devices
LESSON 29
Visual Polish & Immersion Tuning
Map key motion data onto cartoon characters
🎯 Deliverable: Ensure clean visuals — absolutely no skeleton overlay on screen
LESSON 30 Grand Finale
Grand Finale: Human vs AI Showdown
Integrate all code and export the final game build
🎯 Deliverable: William uses motion controls to battle his own max-level AI in the ultimate showdown!
