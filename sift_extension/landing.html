This is not moderation. It is a setting on your own screen.

Platform moderation decides what everybody sees. That is a hard, contested problem and it is not the one Sift is solving. Sift changes only the copy of the page rendered inside your browser. The comment stays up. Other people still see it. Nobody is banned and no report is filed.

The practical difference is who holds the dial. A 17 year old who wants a quieter comment section can have one this afternoon without asking a platform to change its policy.

Sift edits the DOM after the page loads. It never touches the server.

How it works

Four steps, all of them on your computer.

1

Find the comments

A content script walks the page and matches the comment nodes for each supported site. A MutationObserver catches anything loaded later as you scroll.

2

Score the text

The default engine is a small toxicity classifier running in TensorFlow.js. Text never leaves the machine. You can switch to Google's Perspective API if you want the stronger model and accept the network call.

3

Turn it down

Above your threshold, the node gets a blur and a label naming the category and the score. Every hidden comment keeps a Show anyway button. Nothing is removed from the page.

4

Correct it

When it gets one wrong, you press "this is fine". That correction trains a small local layer on top of the base model. Your corrections stay yours.

Second feature

Cool Down rewrites your reply, not theirs.

Filtering handles what arrives. It does nothing about the reply you are three seconds from sending. Cool Down takes what you typed and offers versions that keep the point and drop the heat.

You choose one, edit it, and press send yourself. The extension never posts anything.

Where it gets things wrong

Every toxicity classifier we could run has two failure modes we cannot engineer away. Pretending otherwise would be the fastest way to lose a user's trust, so both are documented in the extension itself and both have a control attached.

Open the fairness panel

It cannot hear sarcasm or affection

"Shut up, you're so funny" from a close friend scores as an insult. A model reading one sentence in isolation has no way to know that. Our answer is not a better classifier, it is more context: Sift keeps a local list of accounts you reply to often, and raises the threshold for them. Warmth between friends is the most common false positive in the category, and relationship history is the only signal that separates it from an attack.

Control: Tuning → People I talk to. The list is stored locally and never uploaded.

It has been documented to over-flag some dialects

Published work has found that widely used toxicity classifiers score African American English and reclaimed in-group slang as toxic at higher rates than equivalent text in other dialects. That is a real, measured problem in the tools this project builds on, not a hypothetical.

Sources: Sap et al., The Risk of Racial Bias in Hate Speech Detection, ACL 2019. Jigsaw, Unintended Bias in Toxicity Classification, 2019.

Control: every hidden comment has a "this is fine" button, and the fairness panel shows your own disagreement rate by category so you can see where the model is failing you specifically.

What leaves your computer

Local engine, the default

Nothing. Model weights download once at install. Scoring happens in the tab. There is no server to send text to.

Perspective API, opt in

Comment text goes to Google's endpoint for scoring. More accurate, and a real privacy trade. Sift shows a banner on every page while it is on.

Usage stats

Off unless you turn it on. If on, it sends counts only: how many comments were scored and hidden. Never the text, never the site, never the author.

Build detail: permissions, model, and the site adapters

Manifest V3 permissions. storage for settings and the local correction set, scripting for the content script, and host permissions limited to the four supported domains. No tabs, no history, no network host beyond the optional Perspective endpoint.

Model. TensorFlow.js toxicity classifier, seven output heads (identity attack, insult, obscene, severe toxicity, sexual explicit, threat, toxicity). Roughly 25 MB of weights cached in IndexedDB after first run. Scoring is batched per animation frame so scrolling stays smooth.

Local correction layer. Corrections train a small logistic layer over the base model's embedding, kept in IndexedDB. It shifts the decision boundary for text like yours without retraining or shipping anything upstream. It is deliberately weak: it can move a threshold, not invent a new category.

Site adapters. One selector module per site, versioned separately from the extension, so a Reddit or X markup change is a small data update rather than a release. Adapters fail open: if selectors stop matching, the page renders untouched and the toolbar icon goes gray.
