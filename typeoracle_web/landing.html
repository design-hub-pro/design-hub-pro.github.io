How it works

From pixel to pairing, in 8 seconds.

A vision-language model trained on 38k labeled UI screenshots maps your design to four signal axes, then a learned ranker proposes pairings.

1
Capture

Drop a screenshot, paste a URL, or pick from 30+ curated UI mockups in the studio library.

2
Read signals

Computes 4 axes — colorfulness, layout density, contrast, text area — using a CLIP-based UI encoder.

3
Classify style

Maps your UI to 7 style classes: Professional, Playful, Luxury, Educational, Dashboard, Creative, Editorial.

4
Pair & rank

Returns top 5 heading + body pairings, ranked by predicted human approval (from 142k ratings).
